# Holistic Conversational AI Agent for Emotional Support (MVP)

**Client:** ZenWell  
**Document Type:** Project Brief / RFP  
**Date Received:** January 20, 2026  
**Status:** Discovery / Evaluation

---

## About the Project

ZenWell is a holistic wellness ecommerce brand offering products and digital experiences to support emotional well-being through a conscious, ethical approach.

We seek a senior freelancer to design and build the MVP of a Conversational AI Avatar integrated into our e-commerce platform.

The Avatar emotionally accompanies users, guides holistic practices and rituals, and assists in correct use of products the user already owns (from ZenWell or other brands).

### Important

This Avatar does **NOT** sell, does **NOT** recommend purchases, and does **NOT** perform clinical or therapeutic diagnoses.

---

## Conceptual Framework (Project Foundation)

The project follows a holistic, integrative approach, treating the person as an interconnected system (mind, emotions, body, behavior, environment, and purpose).

### Key Principles

- Promotes self-awareness, emotional regulation, and user autonomy
- Well-being is a dynamic balance, not a permanent state
- Suggests strategies and rituals without correcting, imposing, or entering the clinical domain
- Clinical symptoms or psychological diagnoses are not treated

The design must consider privacy, data minimization, and responsible use of emotional information.

---

## Profile We Are Looking For

We seek a senior hybrid profile combining strong technical skills, genuine human sensitivity, and real ethical responsibility.

### Valued Experience

- Conversational AI development using LLMs (OpenAI, Claude, or others)
- Ethical, user-centered conversational flow design
- Contextual memory and personalization systems
- Integrations with digital platforms or e-commerce systems
- Projects in wellness, education, digital health, or other sensitive contexts

Experience combining conversational AI with animated visual interfaces, 3D avatars, or voice-based interactions is highly valued.

The freelancer is expected to propose both technical and conceptual decisions.

---

## Role of the Avatar

The Avatar functions as:

- A non-clinical emotional accompaniment companion
- A guide for holistic rituals
- A post-purchase assistant (supporting use of existing products)
- A continuity system for emotional accompaniment, with limited contextual memory

---

## MVP Objective

Build a Conversational AI Avatar that:

- Provides conscious, continuous emotional accompaniment
- Guides holistic rituals and practices (with or without products)
- Assists in correct use of products the user already owns
- Detects emotional risk signals and activates safe referral protocols
- Generates trust, continuity, and genuine human-like support

Success is measured by correct implementation of the 10 deliverables, ethical clarity, and the Avatar's ability to sustain coherent, safe, contextual accompaniment.

---

## MVP Deliverables (10 Detailed Deliverables)

### 1. Overall System Architecture (MVP)

Documented system architecture showing how conversational AI, memory, holistic rituals, and integrations interact, with data flows and responsibilities.

### 2. Conceptual and Ethical Definition of the Avatar

Document defining the Avatar's role, personality, tone, ethical boundaries, and permitted/restricted language, aligned with ZenWell's holistic approach.

### 3. Design of Core Conversational Flows

Structured flows for onboarding, recurring accompaniment, ritual guidance, pauses, session closures, and context resumption, prioritizing emotional safety.

### 4. Functional Conversational AI Agent with 3D Avatar and Chat

Conversational AI agent powered by an LLM with a 3D avatar interface, sustaining coherent conversations, respecting boundaries, and adapting to user context via audio or text in Spanish.

### 5. Structured User Memory System

Persistent memory storing only essential data (name, preferences, active ritual, declared state, summarized progress) without full conversation logs.

### 6. Memory Consent, Control, and Reset Mechanism

Mechanism for explicit user consent, review of stored data, and deletion/reset at any time.

### 7. Contextual Personalization Logic

System adapting responses based on user context, history, and state while maintaining a non-invasive, autonomy-supporting approach.

### 8. Holistic Ritual System (With or Without Products)

Guides holistic rituals performable without products or with products the user already owns (any brand), focusing on conscious use rather than sales.

### 9. Risk Detection and Safe Referral Protocol

Keyword/pattern detection for emotional risk (self-harm, suicidal ideation, severe crisis) with immediate referral to help lines, suicide prevention hotlines, or professionals—without clinical containment.

### 10. Technical and Functional MVP Documentation

Documentation covering architecture, conversational flows, memory, safety protocols, and scaling recommendations that preserve ethical principles.
