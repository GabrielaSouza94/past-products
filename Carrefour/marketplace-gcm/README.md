# Carrefour - CSM (Catalog Management System)

## Project Overview

**Client:** Carrefour Brasil
**Project:** CSM - Catalog Management System
**Engagement Type:** Production
**Status:** Discovery Phase

## Project Summary

Building a custom marketplace management platform (CSM) to replace the Mirakl platform, enabling Carrefour to have full control over marketplace operations including catalog, sellers, orders, promotions, and financial management.
